# QA checklist (fill qa.md; fix every failure before handing over)

## Hook & structure
- [ ] The first spoken line *is* the hook (≤2 s); the first-frame visual is described
- [ ] The hook is true and paid off by the end
- [ ] Archetype stated in brief.md with the viewer's question and the evidence for it (inspiration.md)
- [ ] The script follows that archetype's beat sheet / outline (no generic structure, no merged sheets)
- [ ] Every must-have of the archetype is present; none of its don'ts appear
- [ ] One running example is introduced early and carried through

## Content
- [ ] Zero trivia lines (each line passes the viewer-value test)
- [ ] Every fact has a source tag `[Sx]` that resolves in research.md, with date + label
- [ ] Company claims are worded as claims; unverified items flagged or removed
- [ ] At least one honest catch / limitation
- [ ] YouTube analysis done: winners and low performers watched (or the reason they couldn't be); winners-vs-low findings written
- [ ] Differentiated angle stated (inspiration.md) and no copied lines

## Timing & pacing
- [ ] Runtime within budget (words ÷ 2.7): reel 30–60 s (up to 3 min only if the content needs it, with re-hooks every 30–40 s) · explainer 8–15 min · session 30–60 min
- [ ] Reels: every beat has a visual tag; no beat over 6 s; no 4 s without a visual change; numbers shown on screen when spoken
- [ ] Runtime and pace sit in the winners' range (or the reason it doesn't is written down)
- [ ] Long-form: open loops at ~25% and ~60%, pattern break every 60–90 s, chapters marked

## Visual design
- [ ] art-direction.md filled; palette from the concept, not copied from a reference
- [ ] Every storyboard element has a motion verb; continuous spans marked; a running object persists
- [ ] Section colours change at section breaks; transitions chosen (1 primary + 1–2 accents)

## Delivery & ending
- [ ] Reads naturally aloud; delivery cues present; no words from the avoid list
- [ ] Clean read-aloud text present (no cues, tags or symbols); captions read standalone; names have pronunciation notes
- [ ] CTA present; reels end on a comment question / save prompt and ideally loop to the first frame
- [ ] Publish kit complete (3 titles, thumbnail concept, caption, **sources list**, hashtags, pinned comment, chapters)
- [ ] No sources on screen (they're in the publish kit); mock UIs say "illustrative"
