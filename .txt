# Task: Build the "Jev: The AI That Doesn't Write" reel (v3)

You are building a vertical short-form video (9:16, 60-65 s) from the scene spec below. Work in the repo's existing video pipeline; if none exists, ask me before choosing a stack.

## Goal
Produce one MP4 where each scene's voiceover, header, caption and visual are timed together, and every number appears on screen at the moment it is spoken.

## Hard rules (check these before you say you're done)
1. Story arc: Buzz -> Pivot -> Meet Jev -> Speed -> Cost -> Proof -> Catch -> Fix -> Verdict.
2. Each scene's last line sets up the next scene's opening (see `bridge`).
3. Layer rule: header, caption and visual text never repeat each other.
4. No blank frames. Every frame has a header and a visual.
5. Numbers pop in on the spoken word, not before or after.
6. No views, funding or adoption numbers anywhere.
7. Spoken length ~195 words at ~1.2x pace = 60-65 s. Current VO is ~205 words, so trim if the render runs over 65 s.
8. Sources shown on screen where given (TypeSafe for speed/cost/accuracy, arXiv study for the independent test).

## Suggested workflow
1. Write `scenes.json` from the spec below (one object per scene).
2. Generate VO per scene and measure real durations; do not guess timings.
3. Derive on-screen timings for each `pop` from word-level timestamps.
4. Render each scene, then concatenate.
5. Run a QA pass: total duration, word count, frames with no visual, any repeated text across layers, any banned numbers. Report results as a short checklist.
